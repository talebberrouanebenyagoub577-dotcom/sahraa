# Environment Variables Specification | دليل متغيرات البيئة

نشر 2026 على EasyPanel يستخدم ملفين بلا أسرار، والقيم الحقيقية تُلصق في اللوحة فقط:

- `frontend/env.example` — معرّفات البكسل و`NEXT_PUBLIC_API_URL=https://api.sahraaaaaaaaaaa.shop`
- `backend/env.example` — `DATABASE_URL` ورمز CAPI وسر الجدول

رابط القاعدة الداخلي لا يُكتب في Git. شكله وخطوات الترحيل في [`easypanel.md`](./easypanel.md). صيغ التتبع في [`tracking.md`](./tracking.md).

توثق هذه الصفحة كذلك متغيرات البيئة الحالية للمنصة، وتصنيفها من حيث الإلزامية، وقيمها الافتراضية، ومخاطرها الأمنية.

| **`POSTGRES_PASSWORD`** | **نعم (حرج)** | - | كلمة مرور قاعدة بيانات PostgreSQL (يجب ألا تقل عن 32 خانة). |
| **`POSTGRES_DB`** | نعم | `sahraa` | اسم قاعدة البيانات. |
| **`REDIS_URL`** | **نعم** | `redis://redis:6379` | رابط الاتصال بخادم كاش Redis. |
| **`JWT_SECRET`** | **نعم (حرج)** | - | المفتاح السري لتوقيع Access Tokens (يجب ألا يقل عن 32 خانة عشوائية). |

## 2. قواعد الأمان لمتغيرات البيئة (Security Principles)

1. **حظر الرفع إلى Git (Never Commit `.env`):**
   - ملفات `.env` و `.env.production` و `.env.local` مدرجة بشكل صارم داخل `.gitignore`.
   - لا ترفع أي مفاتيح سرية في مستودع الكود تحت أي ظرف.
2. **عدم كشف الأسرار في الواجهة الأمامية:**
   - أي متغير يبدأ بـ `NEXT_PUBLIC_` يتم حقنه في حزمة الجافاسكريبت الموجهة للمتصفح.
   - **ممنوع تماماً** وضع أي مفتاح سري (مثل `JWT_SECRET` أو `DATABASE_URL` أو `OPENAI_API_KEY`) تحت اسم يبدأ بـ `NEXT_PUBLIC_`.
3. **توليد مفاتيح قوية في الإنتاج:**
   - لتوليد مفتاح آمن في بيئة لينكس:
     ```bash
     openssl rand -base64 48
     ```
