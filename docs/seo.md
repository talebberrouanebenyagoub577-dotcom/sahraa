# Search Engine Optimization (SEO) | تحسين محركات البحث

توثق هذه الصفحة إعدادات ومعمارية السيو (SEO) في منصة **صحرا (SAHRAA)**، والبيانات الوصفية، والخرائط المتعددة اللغات.

---

## 1. توليد البيانات الوصفية الديناميكية (Dynamic Metadata)

تعتمد المنصة على دوال Next.js 15 المدمجة `generateMetadata` لتوليد الترويسات الوصفية لكل صفحة بشكل ديناميكي ومفهرس:

### 1.1 مستوى الـ Root والـ Locale (`src/app/[locale]/layout.tsx`):
- تحديد عنوان الموقع المنسق بحسب اللغة:
  - بالعربية: `صحرا | سوق الخليج للدفع عند الاستلام`
  - بالإنجليزية: `SAHRAA | GCC COD Marketplace`
- الوصف الشامل والكلمات المفتاحية: `SAHRAA`, `COD`, `GCC`, `الدفع عند الاستلام`, `صحرا`, `تسوق أونلاين`.
- روابط محركات البحث القياسية والتبادلية:
  - `canonical`: الرابط الأساسي للصفحة الحالية.
  - `languages`: وسوم `hreflang` للغتين العربية (`/ar`) والإنجليزية (`/en`) ووسم `x-default`.

### 1.2 مستوى صفحة المنتج الفردي (`src/app/[locale]/products/[slug]/page.tsx`):
- العنوان مخصص باسم المنتج وسعره.
- الوصف مأخوذ من وصف المنتج الفعلي في قاعدة البيانات.
- صورة المشاركة (OpenGraph Image) مأخوذة من الصورة الرئيسية للمنتج.

---

## 2. بطاقات التواصل الاجتماعي والمشاركة (OpenGraph & Twitter Cards)

- **OpenGraph:**
  - `og:type`: `"website"` أو `"product"`
  - `og:locale`: `ar_SA` للعربية، و `en_US` للإنجليزية.
  - `og:site_name`: اسم المتجر.
  - `og:image`: شعار الموقع أو صورة المنتج المعروض.
- **Twitter Cards:**
  - `twitter:card`: `"summary_large_image"` لإظهار صور المنتجات بحجم كامل جذاب عند مشاركة الروابط على منصة X (تويتر).

---

## 3. توجيهات محركات البحث والحماية من الفهرسة غير المرغوبة (Robots Directives)

- **الصفحات المفهرسة للعموم (`robots: { index: true, follow: true }`):**
  - الصفحة الرئيسية (`/ar`, `/en`)
  - صفحات الأقسام (`/categories/[slug]`)
  - صفحات المنتجات الفردية (`/products/[slug]`)
  - صفحات من نحن وسياسة المتجر (`/about`, `/privacy`, `/terms`)
- **الصفحات المحمية من الفهرسة (`robots: { index: false, follow: false, nocache: true }`):**
  - صفحة إتمام الطلب (`/checkout`)
  - صفحة الشكر وتأكيد الطلب (`/order/success/[orderId]`)
  - لوحات التحكم (`/dashboard/**`)
  - صفحات تسجيل الدخول والحساب الشخصي (`/auth/**`)
  - يمنع ذلك محركات البحث من أرشفة بيانات المشترين أو أرقام الطلبات الحساسة.
