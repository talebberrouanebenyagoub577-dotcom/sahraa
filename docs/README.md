# SAHRAA Documentation | توثيق منصة صحرا

مرحباً بك في التوثيق الفني والهندسي الشامل لمنصة **صحرا (SAHRAA)**، المنصة المخصصة للتجارة الإلكترونية والدفع عند الاستلام (Cash on Delivery - COD) في دول مجلس التعاون الخليجي (GCC).

---

## 📌 فلسفة المنصة وقواعد العمل الجوهرية (Core Philosophy)

1. **العربية أولاً (Arabic-First RTL):** الموقع مصمم أصلاً للمستهلك الخليجي باتجاه اليمين إلى اليسار (RTL) مع دعم كامل للغة الإنجليزية (LTR).
2. **تجربة دفع عند استلام فائقة السرعة (Frictionless COD):** إلغاء أي تعقيد في الشراء؛ لا حاجة لإدخال بطاقات بنكية، ولا يوجد صفحة سلة تقليدية معطلة، بل نافذة منبثقة (Checkout Popup) تسأل فقط عن **الاسم ورقم الهاتف والمدينة**.
3. **هندسة العروض الثابتة (Volume Pricing Tier):**
   - **منتج واحد:** 199 ريال سعودي
   - **منتجان:** 279 ريال سعودي
   - **3 منتجات:** 349 ريال سعودي
   - الشحن مجاني لجميع الطلبات.
   - لا توجد أكواد خصم عشوائية تخفض من هيبة البراند وقيمته.
4. **عرض الـ Upsell الحصري بعد التحقق (OTO - One Time Offer):**
   - فور إدخال العميل لبياناته والضغط على الطلب، يظهر له عرض لمرة واحدة فقط لمنتج مكمل تم اختياره ذكياً بسعر **99 ريال** مع عداد تنازلي حرج (15 ثانية).
5. **صفحة شكر ترفع معدل التسليم (Delivery-Boosting Thank You Page):**
   - زر تأكيد واتساب بنقرة واحدة لتجاوز فترات الانتظار.
   - تنبيه اتصالات المندوب لضمان الرد وقت التوصيل.
   - إمكانية إضافة منتجات أخرى لنفس الشحنة بالسعر الأصلي (199 ريال) دون رسوم شحن إضافية.

## ⚡ التشغيل السريع للمطورين (Quick Start)

### المتطلبات الأساسية
- Node.js 20+
- Docker و Docker Compose
- PostgreSQL 16
- Redis 7

### خطوات التشغيل المحلي

```bash
# 1. تثبيت الحزم
npm install --legacy-peer-deps

# 2. تشغيل خدمات قاعدة البيانات وريديس
docker compose up -d postgres redis

# 3. إعداد متغيرات البيئة
cp .env.example .env

# 4. تشغيل الهجرة وتغذية البيانات الأولية
npx prisma migrate dev
npm run db:seed

# 5. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000/ar`
