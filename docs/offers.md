# Pricing Engine & Volume Tier Offers | هندسة الأسعار وباقات التوفير

توثق هذه الصفحة القواعد الصارمة للتسعير وباقات التوفير المطبقة في منصة **صحرا (SAHRAA)**، والتي تم تصميمها لمنح المتجر هوية واضحة ومقنعة خالية من الكوبونات المضللة.

---

## 1. قواعد الأسعار الأساسية (Core Pricing Rules)

| كمية المنتجات في السلة | السعر الإجمالي المستحق | الوصف والتوفير المالي |
| :---: | :---: | :--- |
| **منتج واحد (1 Item)** | **199 ريال سعودي** | السعر الفردي الموحد لجميع منتجات المتجر مع شحن مجاني. |
| **منتجان (2 Items)** | **279 ريال سعودي** | باقة التوفير الأولى (توفير 119 ريال مقارنة بشراء قطعتين منفصلتين). |
| **3 منتجات (3 Items)** | **349 ريال سعودي** | أعلى باقة توفير (توفير 248 ريال مقارنة بشراء 3 قطع منفصلة). |

### 1.1 سياسة الشحن
- **الشحن مجاني بالكامل (0 ريال سعودي)** لكافة مدن ومناطق المملكة ودول الخليج.
- لا توجد أي رسوم خفية أو مصاريف دفع عند الاستلام إضافية.

### 1.2 سياسة الكوبونات والخصومات
- **لا يظهر أي كود خصم (Discount Code / Coupon) عشوائي على الموقع.**
- الحفاظ على هيبة ومصداقية العلامة التجارية؛ حيث أن باقات التوفير (199 / 279 / 349) هي الخصم الرسمي والوحيد المتاح في المتجر.

---

## 2. المنطق البرمجي لحساب الكميات الكبيرة (Volume Modulo Logic)

تمت برمجة محرك الحسابات في `src/lib/pricing.ts` عبر دالة `calculateTierPrice(itemCount)` لتغطي أي عدد من المنتجات:

```typescript
export function calculateTierPrice(itemCount: number): number {
  if (itemCount <= 0) return 0;
  const bundlesOf3 = Math.floor(itemCount / 3);
  const remainder = itemCount % 3;
  let remainderPrice = 0;
  if (remainder === 1) remainderPrice = PRICE_TIER_1; // 199 SAR
  else if (remainder === 2) remainderPrice = PRICE_TIER_2; // 279 SAR
  return bundlesOf3 * PRICE_TIER_3 + remainderPrice;
}
```

### أمثلة توضيحية:
- **4 منتجات:** باقة 3 منتجات (349) + منتج إضافي (199) = **548 ريال**.
- **5 منتجات:** باقة 3 منتجات (349) + منتجان (279) = **628 ريال**.
- **6 منتجات:** باقتان من 3 منتجات (349 × 2) = **698 ريال**.

## 3. أماكن عرض وإبراز باقات التوفير في الموقع

1. **الشريط الترويجي العلوي (Promo Banner):**
   - يظهر في أعلى الموقع بجميع الصفحات:
     `منتج واحد: 199 ريال · منتجان: 279 ريال · 3 منتجات: 349 ريال · توصيل مجاني ودفع عند الاستلام`
2. **صندوق الباقات في صفحة تفاصيل المنتج (`ProductActions.tsx`):**
   - جدول مصغر يوضح الأسعار الثلاثة بوضوح قبل الشراء.
   - عند اختيار العميل للكمية `2` أو `3` يتم عرض السعر بعد خصم الباقة تلقائياً بالأخضر.
3. **شريط التحفيز في درج السلة (`CartDrawer.tsx`):**
   - يخبر العميل بالخطوة التالية للحصول على التوفير القادم (مثل: *"أضف منتجاً ثانياً بـ 80 ر.س فقط"*).
4. **نافذة إتمام الطلب (`CheckoutModal.tsx`):**
   - سطر واضح يوضح *"خصم باقة التوفير"* والمبلغ الموفر قبل الضغط على تأكيد الطلب.
