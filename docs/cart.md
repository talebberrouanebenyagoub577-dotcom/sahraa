# Cart Drawer Architecture | معمارية سلة المشتريات والدرج الانزلاقي

توثق هذه الصفحة معمارية وتصميم سلة المشتريات في منصة **صحرا (SAHRAA)**، التي تتبع قاعدة: **لا توجد Cart Page منفصلة، فقط Cart Drawer انزلاقي ذكي**.

---

## 1. فلسفة السلة وتجربة الشراء (CRO Philosophy)

1. **إلغاء صفحة السلة التقليدية (`/cart`):**
   - في التجارة الإلكترونية بنظام الدفع عند الاستلام، الانتقال إلى صفحة سلة تقليدية يتسبب في تسرب نسبة كبيرة من العملاء (Drop-off rate).
   - تم استبدال ذلك بـ **درج انزلاقي (Cart Drawer)** يظهر فوراً على نفس الصفحة دون إعادة التحميل.
   - في حال دخل المستخدم أو المندوب رابط `/[locale]/cart` مباشرة، يتم توجيهه تلقائياً إلى الصفحة الرئيسية مع فتح الـ Drawer بشكل فوري وسلس (`src/app/[locale]/cart/page.tsx`).
2. **شريط باقات التوفير الديناميكي (Volume Tier Dynamic Progress):**
   - يوضح للعميل مقدار التوفير المالي عند إضافة قطع إضافية.
   - عند وجود قطعة واحدة: يظهر تنبيه لإضافة قطعة ثانية بـ 80 ريال فقط (للوصول لباقة الـ 279 ريال بدلاً من 398 ريال).
   - عند وجود قطعتين: يظهر تنبيه لإضافة قطعة ثالثة بـ 70 ريال فقط (للوصول لباقة الـ 349 ريال بدلاً من 597 ريال).
   - عند الوصول لـ 3 قطع: يظهر احتفال بنجاح الحصول على أعلى باقة توفير.

---

## 2. إدارة الحالة ومصدر الحقيقة (State Management)

### 2.1 سياق السلة (`src/lib/context/CartContext.tsx`)
- مصدر الحقيقة الأساسي للواجهة هو `CartContext`.
- يتم حفظ عناصر السلة في التخزين المحلي `localStorage` تحت المفتاح:
  ```typescript
  const STORAGE_KEY = "sahraa_cart_items_v2";
  ```
- يضمن هذا الأسلوب:
  - استمرار محتويات السلة لجميع الزوار (حتى غير المسجلين).
  - سرعة استجابة فائقة فورية (Zero-Latency) عند إضافة المنتجات أو تعديل الكميات.
  - إرسال المنتجات دفعة واحدة إلى `/api/orders` عند تأكيد الطلب.

### 2.2 بنية عنصر السلة (`CartItem`)
```typescript
export interface CartItem {
  id: string;              // مفتاح مركب: `${productId}-${variantId || ""}`
  productId: string;       // معرف المنتج في قاعدة البيانات
  variantId?: string | null;// معرف الخيار المختار إن وجد
  name: string;            // الاسم بالإنجليزية
  nameAr?: string | null;  // الاسم بالعربية
  slug: string;            // رابط المنتج
  image: string;           // الصورة الأساسية
  price: number;           // السعر الأساسي للوحدة (199 ريال)
  quantity: number;        // الكمية المختارة
}
```

### 2.3 كائن الملخص الحسابي (`CartSummary`)
يتم حسابه تلقائياً عبر `useMemo` بناءً على إجمالي عدد القطع:
- `subtotal`: المجموع المحسوب بسعر 199 ر.س لكل قطعة.
- `tierPrice`: المجموع الفعلي بعد تطبيق باقات التوفير (199 / 279 / 349).
- `savings`: قيمة الخصم المالي الفعلي (`subtotal - tierPrice`).
- `shipping`: مجاني بالكامل (0 ر.س).
- `total`: الإجمالي النهائي المستحق للدفع عند الاستلام.

## 3. مكون درج السلة (`src/components/cart/CartDrawer.tsx`)

### الميزات التقنية:
- **تأثيرات بصرية وانتقالات ناعمة:** ينزلق من اليسار في واجهة LTR الإنجليزية، ومن اليمين في واجهة RTL العربية.
- **قفل التمرير (Scroll Lock):** منع تمرير الصفحة الخلفية أثناء فتح الدرج عبر التعديل التلقائي لـ `document.body.style.overflow`.
- **أزرار التحكم بالكمية:** أزرار `+` و `-` مع إمكانية مسح المنتج فورياً عند وصول الكمية للصفر أو بالضغط على أيقونة الحذف.
- **إشارات الأمان والثقة (Trust Badges):**
  - "شحن مجاني وسريع لكافة مناطق المملكة".
  - "معاينة وفحص المنتج قبل السداد".
- **زر الانتقال لإتمام الطلب:**
  - ينقل المستخدم بنقرة واحدة من السلة إلى **Checkout Modal** مع إغلاق الدرج تلقائياً.
