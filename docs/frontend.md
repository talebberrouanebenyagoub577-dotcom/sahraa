# Frontend Architecture | توثيق الواجهة الأمامية

توثق هذه الصفحة بناء الواجهة الأمامية لمنصة **صحرا (SAHRAA)**، موضحّة هيكل المكونات، وإدارة الحالة، وتجربة المستخدم.

---

## 1. حزمة الواجهة الأمامية (Tech Stack)

| التقنية | الإصدار | الوظيفة |
| :--- | :--- | :--- |
| **Next.js** | 15.5.19 | إطار العمل الأساسي (App Router + Server Components) |
| **React** | 19.2.7 | مكتبة بناء واجهة المستخدم |
| **Tailwind CSS** | 4.x | تنسيق الواجهات عبر الفئات المساعدة (Utility Classes) |

| **React Hot Toast** | 2.6.0 | التنبيهات المنبثقة التفاعلية (Toasts) |

## 2. نظام التدويل والاتجاهات (i18n & Bidirectional Support)

- يدعم النظام اللغتين: **العربية (`ar`)** كلغة رئيسية وافتراضية، و**الإنجليزية (`en`)**.
- اتجاه الصفحة يتم ضبطه ديناميكياً في `src/app/[locale]/layout.tsx`:
  - للعربية: `<div lang="ar" dir="rtl">`
  - للإنجليزية: `<div lang="en" dir="ltr">`
- ملفات الترجمة:
  - `messages/ar.json`
  - `messages/en.json`
- ثبات اللغة: مكون `LocalePersistence.tsx` يقوم بحفظ خيار اللغة في كوكيز المتصفح وتعديل الرابط تلقائياً.

## 3. إدارة الحالة على الواجهة (Client State Management)

### 3.1 سلة المشتريات (`CartContext.tsx`)
- الملف: `src/lib/context/CartContext.tsx`
- التخزين المحلي: يُخزن مفتاح `sahraa_cart_items_v2` في `localStorage` لضمان بقاء السلة حتى لو أغلق العميل المتصفح أو كان زائراً غير مسجل.
- الوظائف المعروضة عبر الـ Hook `useCart()`:
  - `items`: مصفوفة المنتجات في السلة.
  - `count`: إجمالي عدد القطع.
  - `summary`: كائن حساب الإجمالي والتوفير والرسائل التحفيزية.
  - `isCartOpen`, `openCart()`, `closeCart()`: التحكم بدرج السلة (Drawer).
  - `isCheckoutOpen`, `openCheckout()`, `closeCheckout()`: التحكم بنافذة الدفع السريع (Popup).
  - `addItem(...)`, `updateQuantity(...)`, `removeItem(...)`, `clearCart()`.

### 3.2 جلسة المستخدم والمصادقة (`AuthContext.tsx`)
- الملف: `src/lib/context/AuthContext.tsx`
- يجلب بيانات المستخدم الحالي من `/api/auth/me`.
- يوفر `user`, `login()`, `logout()`, `refreshUser()`.

### 3.3 إعدادات الموقع (`SettingsContext.tsx`)
- الملف: `src/lib/context/SettingsContext.tsx`
- يوفر إعدادات الشعار، الاسم، روابط التواصل الاجتماعي، ورقم واتساب الدعم من خلال قاعدة البيانات.

## 4. المكونات الرئيسية وتجربة المستخدم (Key UI Components)

### 4.1 رأس الصفحة (`src/components/layout/Header.tsx`)
- شريط العرض الترويجي العلوي (Promo Banner): يبرز عرض الباقات (1 بـ 199، 2 بـ 279، 3 بـ 349) والتوصيل المجاني.
- الشعار والبحث المتقدم الذكي مع الاقتراحات الفورية (`/api/search?type=suggest`).
- مبدل اللغة وقائمة الحساب.
- أيقونة السلة التفاعلية مع شارة عدد المنتجات، والضغط عليها يفتح **Cart Drawer** مباشرة دون الانتقال لأي صفحة أخرى.

### 4.2 درج السلة الانزلاقي (`src/components/cart/CartDrawer.tsx`)
- لوحة منبثقة تنزلق من جهة اليسار (في الإنجليزية) أو اليمين (في العربية).
- إظهار شريط التقدم التحفيزي للباقات وتوفيرها المالي.
- أزرار زيادة وإنقاص الكمية وحذف المنتجات.
- شارات الثقة الخاصة بالدفع عند الاستلام (معاينة قبل الدفع، شحن مجاني).
- زر إتمام الطلب الرئيسي الذي ينقل العميل فوراً إلى **Checkout Modal**.

### 4.3 نافذة إتمام الطلب السريع (`src/components/checkout/CheckoutModal.tsx`)
- مصممة لتقليل الاحتكاك ورفع نسبة التحويل (CRO).
- عداد تنازلي لحجز المخزون (10 دقائق) لخلق جدية الشراء.
- حقول نموذج مبسطة: الاسم بالكامل، رقم الجوال مع كود السعودية `+966`، وقائمة أهم مدن المملكة.
- إمكانية زيادة أو تعديل كميات المنتجات داخل النافذة دون الرجوع للخلف.
- زر تأكيد الطلب المباشر.

### 4.4 نافذة العرض الإضافي الحصري (`src/components/checkout/UpsellModal.tsx`)
- تظهر تلقائياً بعد نجاح التحقق من بيانات النموذج وقبل إرسال الطلب.
- تعرض منتجاً واحداً مكملاً تم اختياره ذكياً بسعر **99 ريال** (خصم 100 ريال).
- شريط تقدم متناقص وعداد حرج لمدة 15 ثانية.
- زر قبول العرض يُضيف المنتج للطلب فورياً ويتم إرساله، أو خيار المتابعة بالطلب الأصلي عند الرفض أو انتهاء الوقت.

### 4.5 صفحة المنتج المتقدمة (`src/components/products/AmazonProductPage.tsx`)
- معرض صور احترافي مع إمكانية التكبير.
- نصوص تحريرية مرافقة لكل صورة (Editorial media blocks) لشرح مميزات المنتج بدقة.
- صندوق باقات التوفير وأزرار الإضافة السريعة للسلة والشراء الفوري (Buy Now) عبر الـ Popup.
- قسم تجارب الزبائن الموثقة وتقييمات النجوم.
- شريط شراء عائم في أسفل الشاشة للهواتف الذكية (Sticky Bottom Buy Bar).

### 4.6 صفحة الشكر وتأكيد الطلب (`src/components/orders/OrderConfirmation.tsx`)
- رسالة شكر ترحيبية باسم العميل مع رقم الطلب وزر النسخ.
- زر التأكيد الفوري عبر واتساب لتسريع الشحن وتقليل نسبة الإلغاء.
- صندوق تنبيه اتصالات مندوب الشحن لضمان رد العميل.
- متتبع مراحل الطلب التفاعلي المكون من 4 مراحل.
- قسم ضمان صحرا الذهبي (معاينة قبل الدفع، منتجات أصلية، استبدال مجاني).
- قسم منتجات البيع التقاطعي (Cross-Sells) بالسعر الأصلي (199 ريال) للإضافة لنفس الشحنة بنقرة واحدة.
